# Contributing

Спасибо за вклад в OpenGym.

## Как предлагать изменения

1. Сделайте fork/ветку от `main`.
2. Держите PR небольшими и тематическими.
3. Добавляйте контекст и мотивацию в описании PR.

## Стандарты

- Пишите понятные коммиты (Conventional Commits приветствуются).
- Обновляйте `CHANGELOG.md`, если меняете публичное поведение.
- Обновляйте документацию вместе с кодом/промптами.

## Мини-чеклист перед PR

- [ ] Изменения локально проверены
- [ ] Нет случайных файлов/секретов
- [ ] README и docs актуальны
