## 4) Challenges and Friction

- Story artifact drift: story files `3-4` and `3-5` were in `review` while practical completion moved forward, creating tracking ambiguity.
- Contract/detail mismatches surfaced during implementation (enum storage approach, transient vs persisted onboarding fields, output formatting expectations).
- Some specification details required reconciliation during execution rather than pre-validated alignment.

## 5) Key Lessons

1. Status governance must be strict: implementation artifacts and sprint tracker must move in lockstep.
2. Deterministic onboarding logic benefits from explicit persistence rules (avoid transient behavior for core profile attributes).
3. Early cross-checking of schema/handler contracts reduces review churn and rework.
4. Test-first validation for edge-cases in handlers substantially improves delivery confidence.
